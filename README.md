# Aviv Charcuterie · אביב שרקוטרי

אתר הדגמה בעברית עבור אביב שרקוטרי, מותאם למחשב ולטלפון. העמוד מציג נקניקיות בעבודת יד, טעימות מתוך המטבח של אביב ודרכים לפנות אליו להזמנה ולתיאום משלוח.

[פתיחת אתר ההדגמה](https://ic3cr1pt.github.io/aviv-charcuterie/) · [צפייה בסיור המצולם במחשב ובטלפון](https://ic3cr1pt.github.io/aviv-charcuterie/presentation.mp4)

## מידע ותמונות

פרטי ההזמנות והמשלוחים מבוססים על הביוגרפיה הציבורית של העסק. שלושת כרטיסי המטבח מתארים מנות מתוך פוסטים שפרסם אביב. זמינות ומחיר מתבררים מול העסק.

- [הפרופיל של אביב](https://www.instagram.com/aviv_charcuterie/)
- [מרגז עם צנוברים בבאגט](https://www.instagram.com/p/DehovoYxMCb/)
- [שתי גרסאות של נקניקיות פרגית](https://www.instagram.com/p/DfKkpQRiRzP/)
- [עראייס מתערובת הבשר](https://www.instagram.com/p/DfcoN_cRVdH/)

תמונות האוכל הראשיות הן הדמיות שנוצרו ב־Kie.ai בהשראת הפוסטים. שלוש התמונות במדור ״המטבח של אביב״ הן תמונות תצוגה מתוך הפוסטים המקוריים ומקשרות אליהם. העיצוב וסימן המותג בראש העמוד הוכנו להצגת הקונספט ללקוח.

## הפעלה מקומית

מתוך תיקיית הפרויקט מריצים את הפקודה הבאה ופותחים את כתובת השרת המקומי בדפדפן.

```sh
python3 -m http.server 8000
```

האתר סטטי. הקבצים, התמונות והגופנים נטענים מהמאגר. האפקט מעל הגריל משתמש ב־WebGL ומכבד את העדפת התנועה המופחתת של הדפדפן. רישיונות הגופנים שמורים בתיקיית הגופנים.
